# Portfolio Site

Fresh rebuild of Jossy Chidi's portfolio as a phone-first, card-led single-page site.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Files

- `index.html`: content structure
- `src/styles.css`: visual system and responsive layout
- `src/main.js`: reveal behavior
- `public/assets/hero-atmosphere.svg`: custom hero backdrop
- `public/assets/*.pdf`: downloadable resumes
